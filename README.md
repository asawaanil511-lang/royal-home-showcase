# RS Toss Book

A private cricket sports betting/gaming web application.

## Tech Stack

- Vite + React + TypeScript
- Tailwind CSS + shadcn-ui
- Express.js API server
- Supabase (Auth + Database)

## Development

```sh
npm install
npm run dev
```

## Deployment

```sh
bash build.sh
NODE_ENV=production node ./dist/index.cjs
```
